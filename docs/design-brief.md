# デザイン依頼：Tsumiage（受験生向け学習アプリ）

スマホアプリの画面デザインを作ってください。自己完結した1枚のHTMLで、
主要な画面を状態ごとに並べたモックにしてください（実装ロジックは不要）。

---

## 0. このアプリの性格（最初に読んでください）

> **自分が覚えたことが、可視化できること。**

これがすべての中心です。デザインで迷ったら、ここに戻ってください。

このアプリは**鏡**です。テストする道具でも、管理する道具でも、
急かす道具でもありません。自分が積み上げてきたものを見て、
「ここまで来た」と分かるためのものです。

だから鏡として、**欠けていても歪んでいてもいけません。**

- 欠けない ＝ 覚えていないものも含めて全体が見える（→ 5-1）
- 歪まない ＝ 覚えたつもりを本当に覚えたことと混ぜない（→ 確認カード）

管理の機能（ペース計算・受験日までの見込み）も入っていますが、
**それは主役ではありません。** 画面で一番大きいのは、いつも
「自分が積み上げたもの」であるべきです。

---

## 1. どういうアプリか

**合格までの道のりを可視化して、忘れる前に復習させ、間に合うペースに導くツール。**

目的は成績管理ではなく、**漠然とした不安を、名前のついた作業に変えること**。
受験生の不安は「何を忘れているか分からない」という形をしていて、
対象が分からないから作業に落ちない。忘れかけている項目を名前で挙げられれば、
それは不安ではなく今日のリストになる。

### 参考書でも問題集でもない

**問題文も答えも持ちません。** 学ぶのは教科書・問題集の側。
このアプリがやるのは、中学数学で学ぶことを「観点」として一覧にして、
次にどれをやるか指し示し、忘れる前に戻すところだけです。

だからカードに出るのは問題ではなく、**「〜できる？」という問いかけ**です。
それを見て、その場で頭の中で答えを作れたかを自分で振ります。

例：
- 「分母に √ がある分数を、有理化して整理できる？」
- 「三角形の合同条件を3つとも言える？」
- 「n角形の内角の和が 180(n−2) になる理由を説明できる？」

---

## 2. 誰が使うか

- **中学3年生が中心**（高校受験）。男女とも使います
- 触る場所は**通学中のスマホ**。片手、縦持ち、数十秒
- PCの前で腰を据えて計画を立てる道具ではありません

## 3. 画面

ボトムタブは3つ。これ以上増やしません。

### 今日
次にやる1つと、受験日の見込みだけ。**選択肢を並べません。**
何をやるか決める作業自体が受験勉強の非効率の一部なので、アプリが決めます。

出るもの：
- 受験まで◯日
- 本番の見込み（％と一言）
- 次にやる1つ（観点名 + なぜそれなのかの理由）
- 今日ぶんの残り
- 開始ボタン

### マップ（ここが一番の課題です）
2つの役割があります。

1. **全部でどれだけあって、どれが埋まっていないかが見える**（→ 5-1 を必ず読んでください）
2. 何と何がつながっているかが、名前で読める
   （「二次関数をやるには一次関数が要る」）

### じぶん
進み具合、受験までの日数、これから薄れそうな観点の一覧。

### 判定カード（全画面）
1枚1観点。左右にスワイプで「あやしい／できた」、上で「完璧」。
誤って振ったらセッション中は1つ戻せます。1セッション5枚。

### 確認カード（数回に1度だけ混ざる）
**このアプリで唯一、答えが出るカードです。** 4択で、選ぶと正誤が出ます。

理由：自己申告だけでは「**逆で覚えていた**」を拾えないからです。
逆に覚えている人は流暢に、確信をもって、間違ったほうを思い出します。
本人の内側では正解と区別がつかないので、即答して「完璧」に振り、
結果として**いちばん出てこなくなります**。忘れただけなら時間が直しますが、
勘違いは安定していて自分では直りません。

なので時々だけ、実際に突き合わせます。1セッションに1枚まで。
**採点しないでください。** このアプリの性格は鏡なので、確認カードの役目は
点をつけることではなく、**鏡のゆがみを直すこと**です。

外したときに出すのは「不正解」ではなく、**絵が変わったこと**。
「覚えたことに入れていたけれど、実はまだだった」と分かればいい。
点数・正答率・連続正解といった、テストの言い方は使わないでください。

例：
> 同じ弧に対する円周角と中心角の関係は？
> [ 円周角は中心角の半分 ] [ 中心角は円周角の半分 ] [ 等しい ] [ 1/4 ]

（誤答の選択肢に必ず「逆」が入っています。そこを選ぶ人を見つけるためのカードです）

## 5. 決まっていること（理由つき）

**理由のほうが大事です。同じ理由を満たすなら、別の解き方で構いません。**

### 5-1. 網羅性とコンプリート欲（いまの最大の弱点）

**ここに一番力を入れてほしいです。**

現状の案は「32 / 55」という集計値と進捗バーしか出しておらず、
**埋まっていない23個が1つずつ見えません。** 集めたくなる仕組みの核は
「持っていないものが個体として見えること」なので、そこが空のままです。
図鑑の空きマス、実績一覧の未取得行にあたるものが無い。

満たしてほしい要件：

- **全体が一度に見渡せる。** 55個が「たくさん」ではなく「55個」として掴めること。
  スクロールしてもいいので、端から端まで見られること
- **埋まっていないものが1つずつ見える。** 集計値だけにしない
- **小さい単位で100%にできる。** 55個を一気に埋めるのは遠すぎるので、
  途中に何度も達成が来るようにする。単元は21個、領域×学年で12区画あります
- **残りが名前で分かる。** 「あと3つ」ではなく「あと3つ（平方完成と解の公式 ほか2つ）」
  のほうが動けます
- **上位の状態がある。** 「完璧」として振った観点は別扱いにできます（後述）

そして、これが効くための決定的な条件：

> **一度そろえたものは、二度と取り消されない。**

忘れても集めた事実は消えません（次項「進捗は後退させない」と同じ理由）。
時間が経つと**色あせるだけ**で、コンプリートの印は残ります。
取り消される達成は、やる気を上げるどころか下げます。

つまり「集めたものは減らない。ただし色あせる」——
この2層があることが、忘却を扱うアプリでコンプリート欲を成立させる鍵です。

素材として使えるもの：
- 観点 55個（これが集める単位）
- 単元 21個 / 領域4つ（数と式・図形・関数・データの活用）／ 学年3つ
- 状態は5つ：未着手 / あやしい / できた / 定着 / **完璧**（上位）
- 「いま覚えている」か「薄れてきた」かの軸が、上の状態とは別にある

### 進捗は後退させない
一度覚えたものを忘れても、**進んだ距離は減らしません。**
受験勉強はすごろくで、忘れたからといってコマは戻らない。
減るのは「いま覚えているか」のほうだけ。

→ 進捗と鮮度を別々に見せる必要があります。
（現状の答えは「積み上げたブロック。置いたら外れず、忘れると色が薄くなる」。
アプリ名が Tsumiage = 積み上げ なので合っていますが、もっと良い表現があれば歓迎）

### 依存関係でロックしない
「一次関数ができていないと二次関数をやれない」——にはしません。
**どの順に覚えるかは本人の自由**で、学習の順序を決めているのは学校や本人であって
アプリではないからです。授業で二次関数をやっている生徒を止めるのは筋が違う。

依存関係は禁止ではなく「ここが苦しいなら、たぶん土台のほうが原因」という**説明**に使います。

### 終わりをはっきりさせる
終わりの来ない画面は、どれだけ進んでも安心には変わりません。
今日ぶんを終えたら、はっきり「終わり」と言い切ります。

### 足りないときは差分で言う
「このままだと足りない」だけでは動けません。
**「1日あと1つ増やせば間に合います」**と、何をすればいいかまで出します。
目的が不安の解消なので、診断だけ渡して終わりにしない。

### 連続日数（ストリーク）は持たない
途切れたときに0に戻るのが、「コマを戻さない」という前提と気持ちの上でぶつかるため。

## 6. やらないでほしいこと

- **ダークテーマ**。学校が配る管理ツールに見えます
- **学習管理ツール／ダッシュボードの見た目**（紺＋グレー、細い文字、表が主役）
- **丸ゴシック**。「かわいい」側に振れすぎます。
  親しみは角丸と厚みで出して、**文字は太いゴシックで強く**保ってください
- **暖色だけ／寒色だけで組む**こと。男女どちらも使うので、どちらかに寄せない。
  ピンク基調も、黒赤の「ゲーミング」系も避けてください
- **選択肢を並べる**こと（次にやることは1つだけ出す）
- **問題文や答えを出す**こと（このアプリは持っていません）
- 造語。「踏む」「踏破」など、中学生に通じない言い方はしないでください

---

## 7. 文言のルール

- 中学生が読んで一発で分かる言葉
- 責めない。「できていない」ではなく「あと◯つ」
- 小数を出さない。「1日あたり必要 0.3」ではなく「今日はあと2つ」
- 数字より言葉を先に。「72% きわどい」のように短い判断を添える

## 8. 実際に出るデータ（これを使ってください。架空の文言を作らないで）

観点名の例：
正負の数の四則 / 文字式の計算（同類項）/ 一元一次方程式 / 比例と反比例 /
連立方程式（加減法・代入法）/ 一次関数の式とグラフ / 三角形の合同条件 /
平行四辺形の性質と条件 / 式の展開 / 因数分解 / 平方根の意味と大小 /
根号をふくむ式の計算 / 二次方程式（因数分解）/ 平方完成と解の公式 /
y = ax² のグラフ / 相似な図形と相似条件 / 円周角の定理 / 三平方の定理 /
四分位数と箱ひげ図 / 標本調査

つながりの例（これが製品の中心です）：
- 三平方の定理 ← 相似の証明と辺の長さ（中3）＋ 根号をふくむ式の計算（中3）
- y = ax² のグラフ ← 一次関数の式とグラフ（**中2**）＋ 二次方程式（因数分解）（**中3**）
- 一次関数の式を求める ← 一次関数の式とグラフ（中2）＋ 連立方程式（中2）

**中2と中3をまたいでつながる**ところが、参考書の目次では見えない部分で、
このアプリの価値そのものです。

数字の例：
- 全部で 55観点、いま 32個 済み
- 受験まで 184日
- 今日ぶん 5つ中 2つ
- 本番の見込み 72%（きわどい）／ 96%（間に合う）
- 「あと4日で薄れる見込み」「31日ぶり」「いま薄れている」

## 9. 出してほしいもの

自己完結した1枚のHTML。スマホの画面枠を並べて、上の10状態が一度に見比べられる形。
CSSは埋め込み、外部フォント・外部画像は使わないでください。

**見た目の解き方は自由です。** 上の「決まっていること」の理由さえ満たしていれば、
配色・レイアウト・進捗の表し方は、こちらの現状案にとらわれず提案してください。
